# WeeComi

Uluslararası teknoloji ekosistemi kurumsal sitesi + admin API.

## Yapı

- backend/ — Express.js + MySQL
- frontend/ — Next.js 16 App Router

## Frontend

cd frontend
npm install
npm run dev

- Next.js 16.2.7, React 19, Tailwind CSS 4, next-intl
- Diller: tr, en, ru, az, ka
- Site: http://localhost:3000
- Admin: http://localhost:3000/admin/login

## Backend

cd backend
npm install
npm run db:setup:dev
npm run dev

- API: http://localhost:8000
- Seed admin: admin@weecomi.com / Admin123!
